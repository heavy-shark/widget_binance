# widget_binance

Виджет для рабочего стола macOS с открытыми позициями на Binance USDⓈ-M Futures. Он показывает токен, текущую цену, цену входа, нереализованный PnL и ROE и обновляется раз в 3 секунды.

```
● BINANCE FUTURES                12:31:31
+469.39 USDT
─────────────────────────────────────────
IDOL  LONG  $1,752               +465.62
0.01815 · вход 0.01333      ROE +531.60%
▬▬───────────────────────────────────────
BLUAI LONG  $1,424                 +3.77
0.0080548 · вход 0.0080334    ROE +2.65%
```

- Сверху показан суммарный нереализованный PnL. Цвет точки показывает свежесть данных: зелёная — данные свежие, жёлтая — обновления задерживаются или пришла ошибка.
- Полоска под позицией показывает, какую часть пути от цены входа до цены ликвидации уже прошла цена. При 30% полоска становится жёлтой, при 60% — красной.
- Клик по позиции открывает её фьючерсную пару на Binance. Клик по шапке открывает самую крупную позицию. Страница открывается в браузере, которым вы пользовались последним: Chrome, Safari, Arc, Brave, Firefox и т.д.

## Как устроено

| Файл | Что делает |
|---|---|
| `widget.py` | Локальный сервер на `127.0.0.1:8765`, написан только на стандартной библиотеке Python. Раз в 3 секунды делает подписанный запрос `GET /fapi/v3/positionRisk` (weight 5), в ответе уже есть mark price и unrealized PnL. Отдаёт JSON по адресу `/api` и HTML-страницу по `/`. Время синхронизирует с сервером Binance. |
| `ubersicht/binance-pnl.jsx` | Сам виджет для [Übersicht](https://tracesof.net/uebersicht/). Раз в 3 секунды читает `/api`. Если один опрос не удался, продолжает показывать последние данные. |
| `open_binance.sh` | Открывает `binance.com/en/futures/<SYMBOL>` в браузере, которым пользовались последним. Браузер определяется по порядку окон из `lsappinfo visibleProcessList`. |
| `index.html` | Та же таблица в виде обычной веб-страницы на `http://127.0.0.1:8765`. |
| `run.sh` | Открывает веб-версию маленьким окном Chrome. Нужен, только если Übersicht не используется. |
| `install.sh` | Устанавливает всё одной командой: службу launchd, Übersicht и сам виджет. |

Ключи хранятся только на сервере и не передаются в браузер или виджет.

## Установка

1. На Binance создай API-ключ **только с правом Enable Reading**: без торговли и без вывода. Желательно включить ограничение по IP.
2. Склонируй репозиторий и заполни ключи:
   ```sh
   git clone https://github.com/heavy-shark/widget_binance.git ~/Projects/binance-widget
   cd ~/Projects/binance-widget
   cp .env.example .env && chmod 600 .env
   # впиши BINANCE_API_KEY и BINANCE_API_SECRET
   ```
3. Запусти установку:
   ```sh
   ./install.sh
   ```
   Скрипт сделает следующее:
   - создаст службу `~/Library/LaunchAgents/pro.hysk.binance-widget.plist`. Сервер будет запускаться при входе в систему и перезапускаться, если упадёт;
   - поставит Übersicht через Homebrew, если его ещё нет;
   - скопирует виджет в `~/Library/Application Support/Übersicht/widgets/`, подставив в него путь к репозиторию.
4. Чтобы виджет появлялся после перезагрузки, добавь Übersicht в автозагрузку: **System Settings → General → Login Items**.

## Настройка

- **Позиция и ширина виджета** задаются в `className` внутри `binance-pnl.jsx` (`top`, `left`, `width`). Изначально виджет стоит под стандартными виджетами погоды и календаря.
- **Порт сервера** задаётся переменной окружения `WIDGET_PORT`, по умолчанию 8765. Если меняешь порт, поменяй его и в `command` виджета.
- **Частота обновления** задаётся в `POLL_SEC` в `widget.py` и в `refreshFrequency` в виджете.

После правки `ubersicht/binance-pnl.jsx` запусти `./install.sh` ещё раз, чтобы скопировать виджет заново. Übersicht подхватит изменения сам.

## Диагностика

```sh
curl -s http://127.0.0.1:8765/api            # данные, которые видит виджет; ошибки Binance в поле "error"
tail -f widget.log                           # лог сервера
launchctl kickstart -k gui/$(id -u)/pro.hysk.binance-widget   # перезапустить сервер
```

- `CERTIFICATE_VERIFY_FAILED`: у Python с python.org нет корневых сертификатов. Сервер берёт системные из `/etc/ssl/cert.pem`.
- `-2015` / `-2014`: неверный ключ, у ключа нет права чтения фьючерсов или IP не в белом списке.
- `-1021`: часы расходятся с сервером Binance. Сервер пересинхронизирует время сам.

## Ограничения

- Показываются только позиции USDⓈ-M Futures. Спот и COIN-M не поддерживаются.
- Только macOS: Übersicht, launchd и `lsappinfo` есть только там.
